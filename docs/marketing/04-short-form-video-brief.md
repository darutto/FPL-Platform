# Short-form motion graphics brief (TikTok / Shorts / Reels)

Status: draft for review. Supersedes the first chat draft: the negative "vs. ChatGPT" concept is removed, Salah is no longer used, and claims are aligned to doc 01.

## Format
- 9:16, 1080×1920, 15–30s, burned-in captions (ES; EN later), within platform safe zones.
- Structure: **hook (0–2s) → feature in motion (2–20s) → "por qué" reason line → CTA end card** (benditofantasy + "5 preguntas gratis al día").
- Brand tokens from `packages/fpl-charts`: dark `#211F29`, coral `#FF6A4D` (CTA), mint `#02EBAE` (positive), gold `#F2C572` (top pick), blue `#1F4B59` (panels).
- Style: the UI recreated as vector cards (crisp, animatable). Kinetic type and bars/cards cut on the beat.
