# Zonal card: one zone set, opportunity framing

Captures of the zones card on a mock Tottenham payload (frontal-central +44%, in-box left +31%), 1440 and 390 px.

- `defensive-before-*`: headline names the frontal-central zone; the pitch draws only the box, so CENTRO reads "≈ media". Coral title and "Débil ..." badge.
- `defensive-after-*`: the pitch also draws the frontal band, so the headline, pitch and verdict name the same zones. Turquoise kicker "Dónde atacar a", badge "Ataca la frontal del área".
- `player-before-*` / `player-after-*`: the player card's zones block. Only the legend text changed ("con ventaja ante un rival favorable").
